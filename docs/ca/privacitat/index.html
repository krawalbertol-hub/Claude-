4. Conservació

Conservem les dades mentre siguin necessàries per atendre la teva sol·licitud i, si arribem a treballar junts, durant la relació i els terminis legals aplicables. Les dades per a comunicacions comercials es conserven fins que retiris el consentiment.

5. Destinataris

No cedim les teves dades a tercers excepte per obligació legal. Podem fer servir proveïdors que actuen com a encarregats del tractament (allotjament web, gestió de formularis, correu electrònic), amb els quals tenim signats els contractes exigits pel RGPD: [LLISTA DE PROVEÏDORS].

Pots exercir els drets d'accés, rectificació, supressió, oposició, limitació del tractament i portabilitat escrivint a contact.orbixel@gmail.com. També pots presentar una reclamació davant l'Autoritat Catalana de Protecció de Dades (apdcat.gencat.cat) o l'Agencia Española de Protección de Datos (www.aepd.es).

Apliquem mesures tècniques i organitzatives adequades per protegir les teves dades, seguint el principi de privacitat des del disseny i per defecte.
